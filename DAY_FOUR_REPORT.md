## Headline findings

1. **Organ-reliance is a universal optimizer-attractor (T041, e063 +
   e063b).** The per-organ load template is invariant across init,
   data order, lineage selection — and even a radical task swap
   (copy-task net with genuinely learned far-retrieval reproduces the
   shape at r = +0.998). This single mechanism explains the e040
   lineage-selection trickle, e059's H-nothing, and T027's
   visibility-limited story: there was no heritable organ-reliance
   variance to select on. Selection didn't fail to see the trait —
   the trait doesn't vary.
2. **The address is a single portable row (T043, e066–e068, e071).**
   The full 256-row census + in-place interventions + rebinding
   surgery localize the installed fact's address to wpe-129 alone:
   necessary (knife-edge), sufficient (~70% expression restored by
   copying that one row to a shifted window's decision position),
   surgically targeted in place (KL 0.2–0.5). The heavier-perturbing
   row 0 (window start, KL 2.6–7.2 distribution-wide) is generic
   scaffolding — destruction weight and address-ness dissociate. The
   deep relay state is a circuit-shaped third thing (not the row, not
   the answer direction, cos ≈ 0.09-0.10 to both).
3. **Cache junk is self-generated — entry-level exposure bias (T045,
   e073).** Negative-utility cache entries concentrate in the free
   run's OWN tokens (4/4 nets; 36.7% of beyond-onset generated entries
   at 10M are lesion-helpful) while corpus-prompt entries almost never
   hurt. The classical TF/free-run mismatch now has a physical
   address: the poison sits in the entries the run itself wrote.
