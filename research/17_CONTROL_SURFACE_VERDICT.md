The project should keep these separate:

- **Behavior control surface:** an intervention reliably changes a behavior under useful controls.
- **Mechanism control surface:** a measured internal signature predicts the behavior, the intervention targets that signature, and reliability checks show the effect is local, robust, and not matched by easier baselines.

`MC-001` on `Qwen/Qwen3-0.6B` found the first kind and failed to prove the second kind.

## Gate Verdict

| Gate | Current MC-001 evidence | Verdict |
| --- | --- | --- |
| Signature | Wrong-hint behavior is cleanly measured. Raw h14 is predictive, but output margin reaches AUC 1.0 and residualized h14 loses most of the useful signal. | behavior signature yes; hidden mechanism signature no |
| Intervention | Raw h14 steering, prompt-prefill steering, and hint-source removal all move truth-following in the predicted direction on hard wrong-hint rows. | pass for behavior control |
| Reliability | Nulls, holdouts, locality checks, source controls, layout/token controls, and side-effect rows were strong enough to demote the mechanism claim. | pass as failed-mechanism evidence |

The right label is:

> `control_without_explanation`

This is not a soft failure. It is a useful result: the model has levers, and the controls tell us which interpretations of those levers are false.

Prompt-prefill steering worked as a narrower additive control.

That is a real source-specific control surface.

## What Failed

The dense h14 story failed as an internal mechanism.

The hidden scalar did not beat the output/logit baseline. Residualization removed the same-layer effect. Nearby-layer application remained active. V7 showed h13 and h14 had nearly identical option-logit transport. V8 showed a separately trained answer-prefix direction did not rescue the dense mechanism route.

The source-token story failed as a localized attention mechanism.

V10 did not find a single head or layer that recovered the V9 effect. V11 found only weak cumulative generation-query source masking. V12 then decomposed the V9 result: full-line input masking reached `63/103`, but literal prompt rewrites reached `57-60/103`; query-only masks stayed at `24/103`. V13 showed character-matched and rendered-token-count-matched neutral rewrites both reached only `52/103`, so layout/token count did not rescue a compact mechanism explanation.

The important failure is not "no effect." The failure is:

> the strongest effects are broad source-removal, prompt-state recomputation, or option-logit transport, not a stable internal signature with local causal semantics.

## Answer To The Main Question

Reliable control surfaces probably exist in learned language systems, but reliability is doing most of the work in that sentence.

The field already has partial examples:

- model editing can update some factual associations while measuring specificity and generalization;
- representation engineering can manipulate population-level representations for scoped behaviors;
- sparse autoencoders can expose interpretable features and sometimes steer behavior;
- circuit tracing can build attribution graphs and validate hypotheses with interventions on supported examples.

Those are existence proofs for controllable internal structure, not blanket proof of deployable mechanism control. The same sources also expose the hard parts: incomplete feature dictionaries, reconstruction error, feature splitting, prompt-local graphs, missing attention mechanisms, side effects, and the gap between steering a token and controlling a behavior robustly.

The repo's MC-001 evidence agrees with that field-level picture. We can move a small LLM. We can document nulls. We can kill bad mechanism stories. We have not yet found a compact internal control surface that passes the mechanism-card contract.

The later MC003 constrained-generation branch reinforces the same answer. It
found a real delayed-copy behavior substrate and strong residual signatures,
including an early `after_wait_newline` layer-14 direction with 0.997 holdout
AUC. The final-prefix signature failed against output margin; the early
signature beat output margin but failed shuffled-label and condition-trace
controls. V3 then built a condition-balanced table inside `wrong_hint_balanced`
with 19 target-copying and 21 distractor-following rows. Once that condition
confound was removed, the selected hidden direction fell to 0.238 holdout AUC.
That makes MC003 another useful failed-signature result, not a mechanism-control
result.

MC004 then tested nonce in-context binding rather than delayed copying. V1
showed clean binding but no pressure contrast. V2 repaired the behavior table
with an original-note versus later-update conflict, selecting
`update_prefer_latest` at 20 original-note answers and 19 update-following
answers. The condition-balanced signature still failed: the selected hidden
direction reached only 0.738 holdout AUC, while same-position output margin
reached 1.000. This strengthens the current answer: the project can build
small-model behavior substrates, but hidden signatures have not yet beaten
simple output observability.
